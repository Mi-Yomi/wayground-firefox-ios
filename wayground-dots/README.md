# Wayground Browser для iPhone

Отдельный форк Firefox iOS с встроенным Wayground Dots. База: Mozilla Firefox iOS `release/v158.1`, коммит `f22e7683f16c8946f7e9f766b925cf8789639d9e`. iOS 17+, Xcode 26.5.

## Сборка и установка

1. В GitHub откройте Actions → **Build Wayground IPA** → **Run workflow**. Сборка не требует сертификата Apple.
2. После успешной сборки скачайте артефакт **WaygroundBrowser-IPA**. Распакуйте ZIP: внутри `WaygroundBrowser.ipa` и SHA-256.
3. Передайте IPA на iPhone через приложение «Файлы», iCloud Drive или AirDrop с Mac. В уже установленном LiveContainer выберите импорт приложения и этот IPA.
4. Откройте Wayground Browser из LiveContainer. Перейдите на `https://wayground.com/join` и войдите в свою учётную запись.
5. Кнопка Dots внизу слева открывает панель. Нажмите «Подключить ИИ». В build 3 выберите **ChatGPT · без API-ключа** → **Продолжить с ChatGPT**, войдите в системном окне iOS и разрешите приложению использовать ваш план. Затем выберите модель, включите ИИ, сохраните настройки и выполните «Проверить ИИ». ПК и сервер проекта не нужны. Альтернатива — собственный API-ключ OpenAI, Gemini или совместимого провайдера.

Сборка IPA не подтверждает запуск в LiveContainer. Требуется реальная проверка на устройстве; её результат должен быть записан отдельно. Расширения Firefox для рабочего стола здесь не устанавливаются: Dots встроен в WebKit браузера.

### Исправление запуска — build 2

Build 1 аварийно завершался в `RustFirefoxAccounts.createAccountManager()`: упаковщик удалял `MozDevelopmentTeam`, а инициализация Firefox Accounts требовала это поле. В build 2 отсутствие команды подписи означает использование стандартной группы Keychain приложения, как в остальном коде браузера. Поле удаляется уже до компиляции, чтобы тест запуска проверял ту же конфигурацию, что и IPA.

Импортируйте новую IPA в LiveContainer поверх прежнего приложения с тем же идентификатором `eu.miyomi.waygroundbrowser`. Не удаляйте контейнер данных ради обновления. В GitHub Actions **Test browser launch** проверяет первый запуск и повторное открытие настоящего приложения в iOS Simulator без отладчика; это отдельная проверка от модульных тестов и не заменяет проверку в LiveContainer.

### Вход через ChatGPT — build 3

Реализован официальный OAuth-поток [Sign in with ChatGPT для открытого приложения](https://developers.openai.com/siwc/token-sharing-open-source/sign-in): динамическая регистрация, PKCE, state, nonce, проверка подписи ID token и разрешения на использование плана. Временный callback слушает только `127.0.0.1` на самом iPhone и закрывается после входа, отмены или тайм-аута. Авторизация завершается в системном окне; код обменивается на токены нативной частью приложения. Cookies ChatGPT не копируются.

Аккаунты, токены и данные регистрации хранятся в отдельном сервисе Keychain. В JavaScript возвращаются только статус, подпись аккаунта и список моделей. Сессия обновляется при истечении срока токена. «Добавить аккаунт» создаёт отдельную регистрацию; при переключении подсказки сбрасываются и ИИ требуется включить заново. «Выйти» пытается отозвать сессию на OpenAI, затем удаляет локальные токены; данные регистрации сохраняются для следующего входа. Если отзыв не подтверждён, интерфейс сообщает об этом и предлагает отключить приложение в настройках ChatGPT.

Модели загружаются из каталога аккаунта OpenAI. Каталог не гарантирует доступ к каждому запросу: успешное завершение проверки ИИ подтверждает работу выбранной модели. Уровень «Автоматически» не задаёт усилие принудительно. Запросы используют лимиты выбранного плана ChatGPT; доступны настройки лимитов и доступа. Реальный вход в LiveContainer и разрешение использования плана требуют проверки самим пользователем. Это подключение к моделям плана, а не запуск Codex CLI на iPhone.

## Поведение и данные

- Код Dots выполняется только в основном фрейме HTTPS-страниц `wayground.com` и `www.wayground.com`, в отдельном `WKContentWorld`.
- Зелёный означает совпавший публичный ключ, жёлтый — предположение ИИ. ИИ включается пользователем и не нажимает ответы.
- Сохраняются распознавание текущего вопроса, публичный источник/PIN, приоритет ключей, отмена устаревшего запроса, размер, видимость и перетаскивание кружков.
- В API передаются текущий вопрос и варианты. Изображения передаются только по отдельному разрешению. Cookies, имя игрока и PIN не отправляются провайдеру ИИ.
- Настройки ИИ с API-ключом и отдельная регистрация ChatGPT хранятся в Keychain; прочие параметры и ограниченный кэш ответов — в локальных настройках приложения. «Удалить настройки ИИ» удаляет настройки и API-ключ, а «Выйти» удаляет токены ChatGPT. При ошибке Keychain нет сохранения ключа в открытом виде.
- В LiveContainer гостевые приложения делят права и контейнер среды запуска; нельзя обещать ту же изоляцию, что при обычной установке. Не импортируйте недоверенные гостевые приложения рядом с ключами.
- Массовая очистка Keychain из исходного Firefox заменена очисткой только сервиса этого браузера; запись ключа Dots находится в отдельном сервисе и сохраняется независимо от сброса профиля браузера.
- Сеть обслуживает `URLSession` без cookies и хранилища паролей. Разрешены Wayground, изображения Wayground/Quizizz и сохранённый HTTPS API; HTTP-переадресации запрещены.
- Компонент Codex для Windows на iPhone не запускается. Build 3 поддерживает самостоятельный вход ChatGPT, а также API OpenAI, Gemini и совместимые HTTPS API.
- Скрипт Tampermonkey и обход прокторинга в сборку не включены. Отдельный JS-контекст не скрывает изменения DOM от сайта.
- Гостевые `.appex` исключены: виджеты, Share Extension и расширение менеджера паролей не входят в IPA.

## Разработка

`src/browser-bridge.js` адаптирует WebExtension API. `src/WaygroundDotsBridge.swift` реализует проверку источника сообщений, Keychain, сеть и настройки. `scripts/build.mjs` собирает ресурсы из мобильной версии Dots. Готовые ресурсы хранятся в `firefox-ios/Client/WaygroundDotsResources` форка; `wayground-dots/extension` содержит их воспроизводимые исходники.

На Mac в корне форка:

```sh
./bootstrap.sh firefox
gem install xcodeproj -v 1.27.0 --no-document
node wayground-dots/scripts/build.mjs wayground-dots/extension firefox-ios/Client/WaygroundDotsResources
ruby wayground-dots/scripts/configure.rb
node --test wayground-dots/tests/*.test.mjs
xcodebuild -project firefox-ios/Client.xcodeproj -scheme Wayground -configuration Debug -destination 'generic/platform=iOS' -derivedDataPath build/Dots -skipMacroValidation CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY= CODE_SIGN_ENTITLEMENTS= build
bash wayground-dots/scripts/package.sh
```

Firefox и изменённые Swift-файлы распространяются по MPL 2.0. Происхождение Screening Choice и остальных компонентов сохранено в `THIRD_PARTY_NOTICES.txt`.

В CI разрешён запуск макроса ModifiedCopy из закреплённой зависимости Firefox (`d020bf8c6432d0c6aa8428b5ca1c3225a0545b3b`); интерактивное подтверждение Xcode для него отключено флагом `-skipMacroValidation`.
